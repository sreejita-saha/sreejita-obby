# Projects

I enjoy building practical software across web, mobile, desktop, systems, and hardware. These projects show how I take an idea, work through the technical detail, and turn it into something people can use.

## WhatSaS Secure Messaging Platform

I helped build a secure messaging platform with both desktop and web clients. Users can create accounts, sign in, and exchange encrypted messages.

I worked across the C++, Python, and JavaScript parts of the system. My work included authentication, end-to-end encryption, secure key management, encrypted message storage, and frontend development. This project strengthened my ability to work across a larger codebase while keeping security and the user experience in mind.

**Technologies:** C++, Python, JavaScript

**Skills demonstrated:** authentication, encryption, key management, secure storage, desktop and web development

## LaRo Beam

I contributed to a portable emergency communication device for situations where mobile networks are unavailable. LaRo Beam uses LoRa mesh networking and GPS to support long-range messaging and location sharing, with a physical SOS function that works without a phone.

I worked on the prototype, product design, and 3D-printed enclosure. The project gave me hands-on experience moving from a technical idea to a physical product, while thinking about reliability and use in an emergency.

**Technologies:** LoRa mesh networking, GPS, 3D printing

**Skills demonstrated:** hardware prototyping, product design, offline communication, location sharing

## Rep It Workout Tracking App

I built a native Android app in Kotlin to help people plan and track their workouts. Users can create workout sessions and record exercises, sets, and repetitions.

I focused on making the experience simple and useful, so people can quickly log their training and look back at their progress.

**Technologies:** Kotlin, Android

**Skills demonstrated:** mobile development, user-focused design, workout planning, data entry flows

## ISE Jobs Board

I built a Python application to manage students and available placement roles for an ISE course jobs board.

The project includes an automated allocation algorithm that matches students to roles using their preferences and placement constraints. It challenged me to turn a real-world matching problem into clear application logic that considers the needs of students, employers, and the course.

**Technologies:** Python

**Skills demonstrated:** algorithm design, preference matching, placement management, problem-solving

## Linux IPC Driver

I developed a Linux kernel driver in C for secure inter-process communication. The project includes encryption and synchronisation using mutexes and semaphores.

Working at operating-system level helped me build a stronger understanding of concurrency, shared resources, and how lower-level software supports reliable applications.

**Technologies:** C, Linux kernel development

**Skills demonstrated:** systems programming, inter-process communication, encryption, concurrency, synchronisation

## System Hardware Monitor

Using native libraries with a Java Swing interface, I connected a clear desktop UI to lower-level system information. This project developed my confidence in Java desktop development and working across application and system layers.

**Technologies:** Java, Java Swing, native libraries

**Skills demonstrated:** desktop development, system monitoring, UI development, native-library integration

## Interactive Portfolio

I built this interactive portfolio as a Roblox-obby-inspired experience. Instead of scrolling through a static page, visitors move through checkpoints to explore my education, experience, skills, and projects.

I built it with React, TypeScript, Three.js, React Three Fiber, Vite, and Supabase. It brings together my interest in web development, game ideas, and user experience, and shows how I use technology to make information more engaging.

I also built a RAG-powered portfolio assistant using Gemini, Supabase vector search, and Vercel serverless functions. It retrieves relevant portfolio content before answering questions, which keeps answers about my background and work grounded in the information I have provided. I added rate limiting and feedback collection so the feature is practical to deploy as well as interactive.

**Technologies:** React, TypeScript, Three.js, React Three Fiber, Vite, Gemini, Supabase vector search, Vercel serverless functions

**Skills demonstrated:** interactive 3D web development, frontend engineering, RAG architecture, vector search, serverless APIs, user experience, game-inspired interface design
