# Projects

## WhatSaS Secure Messaging Platform

A secure messaging platform with desktop and web clients. Users can create accounts, log in, and send encrypted messages.

I worked across the C++, Python, and JavaScript parts of the system, including authentication, end-to-end encryption, secure key management, encrypted message storage, and frontend development.

**Technologies:** C++, Python, JavaScript

**Topics:** authentication, encryption, key management, secure storage, desktop client, web client

## LaRo Beam

A portable emergency communication device designed for situations where mobile networks may not be available. It uses LoRa mesh networking and GPS to support long-range messaging and location sharing, and includes a physical SOS function that can be used without a phone.

I worked on the prototype, product design, and 3D-printed enclosure.

**Technologies:** LoRa mesh networking, GPS, 3D printing

**Topics:** emergency communication, offline communication, hardware prototype, location sharing

## Rep It Workout Tracking App

A native Android app built with Kotlin to help people organise and track workouts. Users can create workout sessions and record exercises, sets, and repetitions.

**Technologies:** Kotlin, Android

**Topics:** mobile development, workout planning, exercise tracking

## ISE Jobs Board

A Python application based on the ISE course jobs board, designed to manage students and available placement roles. It includes an automated allocation algorithm that matches students to roles according to their preferences and placement constraints.

**Technologies:** Python

**Topics:** allocation algorithm, preference matching, placement management

## Linux IPC Driver

A Linux kernel driver written in C for secure inter-process communication. The project includes encryption and synchronisation using mutexes and semaphores.

**Technologies:** C, Linux kernel development

**Topics:** inter-process communication, encryption, mutexes, semaphores, systems programming

## System Hardware Monitor

A Java desktop application that displays real-time laptop hardware information, including CPU, memory, storage, and general system details. It uses native libraries with a Java Swing interface.

**Technologies:** Java, Java Swing, native libraries

**Topics:** desktop application, system monitoring, hardware information

## Interactive Portfolio

An interactive portfolio inspired by Roblox obbies. Visitors move through checkpoints to explore education, experience, skills, and projects.

Built with React, TypeScript, Three.js, and React Three Fiber, the project explores how a portfolio can feel more like an experience than a static page.

**Technologies:** React, TypeScript, Three.js, React Three Fiber, Vite, Supabase

**Topics:** interactive 3D website, portfolio, game-inspired user interface
